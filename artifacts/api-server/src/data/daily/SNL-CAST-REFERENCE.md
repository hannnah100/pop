# SNL MAIN CAST REFERENCE FOR REEL CONNECTIONS

## Rule
If two actors were both SNL MAIN CAST MEMBERS during overlapping seasons, "SNL" and "Saturday Night Live" are valid answers for their connection.

## Criteria
- Must be official repertory cast members or featured players
- Writers, correspondents, hosts, guests DO NOT count
- Must have overlapping seasons (even 1 season counts)
