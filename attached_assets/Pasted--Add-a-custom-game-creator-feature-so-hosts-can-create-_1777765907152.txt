"Add a custom game creator feature so hosts can create their own questions and game boards for Wheel of Fortune, Jeopardy, and Pub Quiz.
Where it lives:
Add a new button on the Host a Game screen: "Create Custom Game" (with Y2K styling - thick border, bright color).
When clicked, host chooses which game type to customize:

Custom Jeopardy Board
Custom Wheel of Fortune Puzzles
Custom Pub Quiz Questions

Custom Jeopardy Board Creator:
Interface for host to build their own Jeopardy board:

Name your game (text input): e.g., "Friends Trivia Night"
Create 6 categories (text inputs for category names)
For each category, create 5 questions with answers:

Dollar value: $200, $400, $600, $800, $1000 (pre-set, not editable)
Question text (text area)
Answer text (text input)


Mark 2 questions as Daily Doubles (checkboxes)
Save board button

After saving:

Board appears in a "My Custom Games" list
Host can select it when starting a Jeopardy game (alongside pre-loaded packs)
Host can edit or delete custom boards

Custom Wheel of Fortune Puzzles:
Interface for creating puzzle packs:

Name your puzzle pack (text input): e.g., "90s Nostalgia"
Choose category for each puzzle (dropdown: Song Titles, Movie Titles, Famous Quotes, Pop Culture Phrases, TV Shows, Celebrity Names, Places, Things)
Add puzzles (minimum 10, maximum 50):

Puzzle phrase (text input, converts to all caps automatically)
Optional hint (text input)


Preview shows what the puzzle board will look like with blanks
Save pack button

After saving:

Pack appears in "My Custom Games" list
Host can select it when starting Wheel of Fortune (alongside pre-loaded packs)
Host can edit or delete custom packs

Custom Pub Quiz:
Interface for creating quiz rounds:

Name your quiz (text input): e.g., "Office Trivia"
Create rounds (minimum 3, maximum 7):

Round name (text input): e.g., "Round 1: Character Quotes"
Round type (dropdown): Multiple Choice, True/False, Open-Ended
Number of questions (5-20 per round)



For each question:

Question text (text area)
If Multiple Choice: 4 answer options (text inputs) + mark which is correct (radio buttons)
If True/False: mark correct answer (True or False radio buttons)
If Open-Ended: accepted answer(s) (text inputs, can add multiple accepted variations)
Points value (default 1, can change to 2 for harder questions)
Save quiz button

After saving:

Quiz appears in "My Custom Games" list
Host can select it when starting Pub Quiz (alongside pre-loaded games)
Host can edit or delete custom quizzes

Storage:

Save custom games to the database (not just localStorage)
Link to the host's session/account (if no accounts yet, use browser localStorage as temporary storage)
Custom games persist between sessions
When creating a room, host can choose: "Pre-loaded Games" or "My Custom Games"

My Custom Games Page:
Add a "My Custom Games" link in navigation that shows:

List of all custom games the host has created
Organized by game type (Jeopardy, Wheel, Pub Quiz)
Edit button (opens creator with pre-filled data)
Delete button (with confirmation: "Are you sure?")
Duplicate button (makes a copy to edit)
Play button (starts a game with that custom content immediately)

Design:
Use the same Y2K aesthetic:

Form inputs with thick black borders
Bright colored section headers
Large touch-friendly buttons
Comic book text styling for headings
Add/Remove buttons styled as cartoon stickers
Preview sections with colorful backgrounds

Mobile Responsive:
Make the creator interfaces work on both desktop (easier for typing lots of questions) and mobile (large inputs, stack fields vertically).
Validation:

Ensure all required fields are filled
Show error messages if host tries to save incomplete game
Jeopardy must have exactly 30 questions (6 categories × 5 questions)
Wheel must have at least 10 puzzles
Pub Quiz must have at least 3 rounds with at least 5 questions each

Make it easy and fun to use - hosts should be able to create a custom game in 10-15 minutes."
