**How Crosswords Work - Follow These Rules:**

- 3×9 grid (3 columns, 9 rows)
- White squares = letters
- Black squares = blockers/separators

- Minimum word length: 3 letters

**Numbering System (CRITICAL):**
- Number squares that START a word
- Number from left to right, top to bottom
- If a square starts BOTH an across AND a down word, it gets ONE number used for both clues
- Only number the starting squares, not every square

Example numbering:
```
Row 1: [1][2][■]
Row 2: [3][4][5]
Row 3: [■][6][7]
```

If square 1 starts "TAYLOR" going across AND "TIKTOK" going down:
- 1-Across: "Swift or Lautner (6)" → TAYLOR
- 1-Down: "Viral dance app (6)" → TIKTOK

**Clue Format:**

- Include letter count in parentheses: (6) means 6 letters
- Count must be accurate - verify by counting letters in answer
- Clue text should be solvable but not too easy
