RAINBOW TEXT STYLE (Like Room Codes):
How the Room Code Style Works:
Each letter gets its own color from the rainbow spectrum, creating that vibrant multi-color effect.
Example: Room code "BUZZ"
B = Red
U = Orange  
Z = Yellow
Z = Green
Apply This Style to ALL Major Text Elements:
1. Logo "POP: THE QUESTION"
P = Red
O = Orange
P = Yellow
: = Green (or skip punctuation)
T = Cyan
H = Blue
E = Pink
(continue through rainbow, cycling back)
2. Game Title Cards:
"THREE STRIKES"
T = Red
H = Orange
R = Yellow
E = Green
E = Cyan
(space)
S = Blue
T = Pink
R = Magenta
I = Red (cycle restarts)
K = Orange
E = Yellow
S = Green
3. Player Names in Games:
Each player's name displays in rainbow letters
"SARAH" = S(red) A(orange) R(yellow) A(green) H(cyan)
"MIKE" = M(red) I(orange) K(yellow) E(green)
4. Score Numbers:
Big scores use rainbow per digit
"1,250" = 1(red) ,(orange) 2(yellow) 5(green) 0(cyan)
5. Homepage Headings:
"DAILY GAMES" = each letter different rainbow color
"HOSTED PARTY GAMES" = each letter different color

ANIMATION STYLES:
Shimmer Effect (for important elements):
css@keyframes rainbow-shimmer {
  0% { filter: hue-rotate(0deg); }
  100% { filter: hue-rotate(360deg); }
}

.shimmer-text {
  background: linear-gradient(90deg, 
    #FF0054, #FFD700, #00D9FF, #FF006E, #FF0054);
  background-size: 200% auto;
  animation: rainbow-shimmer 3s linear infinite;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}
Flowing Rainbow (for backgrounds):
css@keyframes rainbow-flow {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

DARK BACKGROUND ADJUSTMENT:
Since using dark mode (#0A0A0F background), rainbow colors POP beautifully.
Add subtle rainbow accents to dark background:
cssbody {
  background: #0A0A0F;
  background-image: 
    radial-gradient(circle at 20% 80%, rgba(255, 0, 84, 0.1) 0%, transparent 50%),
    radial-gradient(circle at 80% 20%, rgba(0, 217, 255, 0.1) 0%, transparent 50%),
    radial-gradient(circle at 40% 40%, rgba(255, 215, 0, 0.05) 0%, transparent 50%);
}
This creates subtle colored glows in the background without being overwhelming.
