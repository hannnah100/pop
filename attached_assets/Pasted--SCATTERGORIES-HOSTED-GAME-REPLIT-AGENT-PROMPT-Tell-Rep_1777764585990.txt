## **SCATTERGORIES HOSTED GAME - REPLIT AGENT PROMPT**

---

**Tell Replit Agent:**

"Build a new hosted party game called Scattergories with automatic point scoring.

**CRITICAL: Use Y2K design aesthetic - bright colors, thick black borders, comic book text styling.**

**How It Works:**

Host picks categories and a random letter. Players have 60 seconds to type one answer for each category that starts with that letter. Unique answers get points.

**Game Flow:**

1. **Host Setup:**
   - Choose number of rounds (3-5)
   - Choose difficulty (Easy/Medium/Hard - affects categories)
   - Start game

2. **Each Round:**
   - Host screen shows: random letter (big and bold) + 8-12 categories
   - Players see same letter + categories on their phones
   - 60-second timer starts
   - Players type one answer per category (must start with the letter)

3. **During Round:**
   - Timer counts down prominently
   - Players type answers in text boxes (one per category)
   - Can edit answers until time runs out
   - Submit button or auto-submit when timer hits 0

4. **After Time's Up:**
   - Collect all answers
   - Auto-scoring happens:
     - If your answer is UNIQUE (nobody else wrote it): 1 point
     - If your answer is SHARED (someone else also wrote it): 0 points
     - If you left it blank: 0 points
   - Host screen shows all answers + who wrote what
   - Leaderboard updates

5. **Next Round:**
   - New random letter
   - New set of categories
   - Repeat

6. **Game End:**
   - Final leaderboard
   - Winner announced
   - Podium display

**Auto-Validation Rules:**

For answers to count, they must:
1. Start with the correct letter (case insensitive)
2. Be a real answer (not gibberish)
3. Match the category reasonably

**Fuzzy Matching:**
- "Taylor Swift" = "taylor swift" = "TAYLOR SWIFT" (same answer)
- Handle typos minimally: "Tylor Swift" might count as duplicate
- Articles ignored: "The Office" = "Office"
- But: "Tom Cruise" ≠ "Tom Hardy" (different answers)

**Letters to Use:**

Common letters that work well:
- A, B, C, D, F, G, H, J, K, L, M, N, P, R, S, T, W

Exclude rare letters:
- Q, X, Z (too hard)
