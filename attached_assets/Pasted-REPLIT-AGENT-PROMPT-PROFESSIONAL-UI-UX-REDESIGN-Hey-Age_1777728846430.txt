Hey Agent! I need a sophisticated UI/UX redesign for Pop: The Question. The current implementation is too childish and overdone. Here's the refined design system:

TYPOGRAPHY SYSTEM
Font Hierarchy (Import from Google Fonts):
1. Display Font (Logo, Major Headlines):

"Syne" (ExtraBold, 800 weight) OR "Archivo Black"
Used for: Main logo, game mode titles, big celebration moments
Characteristics: Bold, impactful, modern but not playful
Example usage: "POP: THE QUESTION", "THREE STRIKES", "GAME OVER"

2. Heading Font (Section Titles, UI Headers):

"Inter" (SemiBold, 600 weight) OR "Manrope" (Bold, 700)
Used for: Section headings, card titles, player names, scores
Characteristics: Clean, strong, professional yet energetic
Example usage: "Daily Games", "Leaderboard", "Round 3"

3. Body/UI Font (Everything Else):

"Inter" (Regular 400, Medium 500)
Used for: Paragraph text, buttons, labels, questions, answers
Characteristics: Highly readable, neutral, professional
Example usage: All body copy, form inputs, descriptions

4. Accent Font (Sparingly - Special Moments Only):

"Space Grotesk" (Bold, 700) OR "Bebas Neue"
Used ONLY for: Countdown timers, big score reveals, "NEW RECORD" banners
Characteristics: Condensed, impactful, creates contrast
Limit to 5% of all text

Font Rules:

Never use more than 3 font families on a single screen
Body text is always Inter for consistency and readability
No rounded "kiddie" fonts like Fredoka, Comic Sans, or bubbly typefaces
Typography should feel modern editorial (think Pitchfork, Hypebeast, The Verge)


RAINBOW TEXT - STRATEGIC USE ONLY
Where to Apply Multi-Color Letter Treatment:
PRIMARY (Always Rainbow):

Main logo: "POP: THE QUESTION" only
Room codes (keep current style - this works well)

SECONDARY (Selective Rainbow):
3. Player names in leaderboards (but NOT in general UI)
4. Winning scores above 1000 points
5. "NEW RECORD" or "STREAK: 10 DAYS" milestone text
NEVER Rainbow:

Section headings ("Daily Games", "Hosted Party Games")
Game mode titles ("Three Strikes", "Jeopardy")
Button text
Body copy
Question text
Navigation menus
Form labels
Helper text

Rainbow Implementation Rules:
When you DO use rainbow text:

Color sequence: Red (#FF0054) → Orange (#FF6B35) → Yellow (#FFD700) → Green (#00F5A0) → Pink (#FF006E) → Magenta (#FF1493)
Each letter cycles through this palette
No animation on rainbow text (static colors only)
High contrast ratio maintained (text must be readable)

If less than 10% of text on a page is rainbow, you're doing it right.

Core Colors:

Neutrals:

--text-primary: #FFFFFF
--text-secondary: #B8B8C8
--text-muted: #6B6B7B

Functional:
--success: #00F5A0
--warning: #FFD700
--error: #FF0054
How to Use Colors:
Backgrounds:

Primary background: --bg-dark (very dark, almost black)
Card backgrounds: --bg-card (slightly lighter dark)
Accent backgrounds: Subtle gradients using 2-3 rainbow colors at 10% opacity

Text:

90% of text: White (#FFFFFF) or --text-secondary
Headings: White
Labels/descriptions: --text-secondary
Disabled/muted: --text-muted
Rainbow treatment: <10% of all text

UI Elements:

Buttons: Gradient backgrounds (but text stays white)
Borders: Single accent color OR subtle gradient
Icons: Single color from palette (match context)
Focus states: Colored glow (single color, not rainbow)

Gradients (Use Strategically):
css/* Button gradient - warm flow */
background: linear-gradient(135deg, #FF0054 0%, #FF6B35 50%, #FFD700 100%);

/* Card hover - subtle accent */
border: 2px solid transparent;
background: 
  linear-gradient(#1A1A24, #1A1A24) padding-box,
  linear-gradient(90deg, #FF006E, #FFD700) border-box;

/* Success moment - celebration gradient */
background: linear-gradient(180deg, #FFD700 0%, #00F5A0 100%);

VISUAL HIERARCHY PRINCIPLES
Contrast & Focus:
Level 1 (Highest Attention):

Logo
Room codes
Primary CTAs
Current scores in active game

Use: Rainbow text OR bold gradients OR large scale
Level 2 (Secondary Attention):

Section headings
Game mode titles
Player names
Card titles

Use: White text, larger size, heavier weight, optional colored underline
Level 3 (Supporting Info):

Descriptions
Labels
Helper text
Timestamps

Use: --text-secondary, smaller size, regular weight
Spacing & Rhythm:
Spacing Scale:
--space-xs: 4px
--space-sm: 8px
--space-md: 16px
--space-lg: 24px
--space-xl: 32px
--space-2xl: 48px
--space-3xl: 64px
Apply generously:

Cards: 24px padding minimum
Between sections: 48px-64px
Button groups: 16px gap
Text line-height: 1.6 for body, 1.2 for headings

Animation Principles:
Subtle, Purposeful Motion:

Button hover: 2-3px lift, 0.3s ease
Card hover: Border color change, subtle scale (1.02x)
Page transitions: Fade + slide (300ms)
Score updates: Count-up animation (500ms)
Confetti: Only on major wins (game completion, new record)

NO:

Constantly shifting gradients
Pulsing elements (except timers under 10s)
Excessive parallax
Shake effects (only for errors)

FINAL PRINCIPLES
Bold, Not Childish:

Strong typography creates impact without playfulness
Color used strategically, not everywhere
White space and hierarchy guide the eye
Professional enough for a pitch deck, fun enough for a party

Colorful, Not Chaotic:

Rainbow palette exists, but most UI uses white text
Gradients on backgrounds and accents, rarely on text
Each color has a purpose (success = green, warning = yellow)
If you're unsure, default to white text

Modern, Not Trendy:

Clean lines, good spacing, readable fonts
Animations enhance, don't distract
Mobile-first, accessibility-minded
Feels 2025, not 2015
